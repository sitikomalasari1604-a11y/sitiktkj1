01

Pengertian Sistem Operasi Linux

Linux adalah sistem operasi (Operating System) yang bersifat open source atau sumber terbuka. Linux digunakan untuk mengelola perangkat keras dan perangkat lunak pada komputer.

Linux banyak digunakan pada komputer, server, jaringan komputer, dan perangkat lainnya. Sederhananya, Linux merupakan sistem operasi seperti Windows, tetapi memiliki cara penggunaan dan pengelolaan yang berbeda.

02

Fungsi Sistem Operasi Linux

  • • Mengatur kerja perangkat keras komputer.
  • • Menjalankan aplikasi dan program.
  • • Mengelola file dan folder.
  • • Mengatur pengguna dan hak akses.
  • • Mengelola jaringan komputer.
  • • Menjalankan layanan server.
03

Jenis-Jenis Linux (Distro Linux)

Linux memiliki beberapa jenis distribusi atau biasa disebut distro:

1. Ubuntu

Linux yang cukup mudah digunakan oleh pemula dan banyak digunakan untuk desktop maupun server.

2. Debian

Sistem operasi Linux yang dikenal stabil dan banyak digunakan untuk server.

3. Linux Mint

Linux yang memiliki tampilan sederhana dan cocok untuk pengguna pemula.

4. Kali Linux

Linux yang banyak digunakan untuk pembelajaran keamanan jaringan dan pengujian keamanan secara legal.

5. Fedora

Distribusi Linux yang menyediakan teknologi dan perangkat lunak terbaru.

04

Kelebihan dan Kekurangan Linux

Kelebihan

  • • Gratis dan open source.
  • • Relatif aman.
  • • Stabil untuk menjalankan server.
  • • Bisa dikembangkan dan dimodifikasi.
  • • Mendukung berbagai aplikasi jaringan.

Kekurangan

  • • Beberapa pengguna perlu beradaptasi dengan tampilannya.
  • • Tidak semua aplikasi Windows tersedia secara langsung.
  • • Penggunaan terminal membutuhkan pemahaman perintah.
  • • Beberapa perangkat membutuhkan konfigurasi tambahan.
05

Dalam Linux, kita bisa menggunakan Terminal untuk memberikan perintah kepada komputer:

07

Contoh Praktik Linux

Misalnya kamu ingin melihat IP Address komputer menggunakan Linux:

  1. Buka Terminal.
  2. Ketik perintah ip a lalu tekan Enter.
  3. Linux akan menampilkan informasi jaringan, termasuk alamat IP yang dimiliki komputer.
$ ip a
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    inet 192.168.1.15/24 brd 192.168.1.255 scope global eth0
08

Kesimpulan & Saran Belajar TKJ

Linux merupakan sistem operasi open source yang banyak digunakan dalam dunia TKJ, terutama untuk mengelola jaringan komputer dan menjalankan layanan server. Linux memiliki berbagai perintah terminal yang membantu administrator jaringan melakukan konfigurasi dan pengelolaan sistem.

Saran belajar TKJ: Setelah memahami pengertian Linux dan perintah dasarnya, lanjutkan ke praktik Linux menggunakan VirtualBox, kemudian belajar konfigurasi IP Address, DHCP Server, DNS Server, dan Web Server.
